# DEMS Architecture & Design Artifacts

This directory is reserved for system architectural blueprints and visual documentation.

## Document Placeholders

1. **Architecture Diagram** (`docs/architecture_diagram.png` / `.mermaid`)
   - High-level layered monolith architecture showing Web/API, Service Layer, Repositories, and Storage.

2. **ER Diagram** (`docs/er_diagram.png` / `.mermaid`)
   - Entity-relationship diagram for Cases, Evidence Files, Audit Logs, and Chain of Custody records.

3. **API Flow Diagram** (`docs/api_flow_diagram.png` / `.mermaid`)
   - Request processing pipeline including Security Filters, Controller Validation, Service Execution, and Exception Handling.

4. **Sequence Diagrams** (`docs/sequence_diagrams/`)
   - Detailed sequence interactions for key lifecycle workflows (Evidence Ingestion, Hash Verification, Custody Transfer).
